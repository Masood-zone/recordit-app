Design the Reports, Analytics, Settings, and final polished UI screens for RecordIT.

RecordIT is a biometric-based multi-school attendance monitoring and reporting system. The system should feel complete, professional, academic, secure, and user-friendly.

Use the RecordIT color theme:

- Deep Navy: #071B52
- Royal Blue: #005BBB
- Bright Cyan: #00AEEF
- White: #FFFFFF
- Slate Gray: #5B677A
- Light Background: #F5F7FA

Create the following screens:

1. Reports Dashboard

- Page title: Attendance Reports
- Report filters:
  - School
  - Class
  - Student
  - Date Range
  - Academic Term
  - Attendance Status
- Report type cards:
  - Daily Report
  - Weekly Report
  - Monthly Report
  - Termly Report
  - Custom Report
- Buttons:
  - Generate Report
  - Export PDF
  - Export Excel
  - Export CSV

2. Attendance Analytics Page

- Summary cards:
  - Average Attendance Rate
  - Total Absences
  - Total Late Arrivals
  - Best Attendance Class
  - Students Needing Attention
- Charts:
  - Attendance trend over time
  - Present vs Absent comparison
  - Class attendance ranking
- Table:
  - Students with repeated absenteeism
  - Students with repeated lateness

3. Student Monitoring Page

- Search student
- Student attendance profile
- Attendance percentage
- Absence history
- Lateness history
- Parent/guardian contact
- Suggested action section:
  - Contact Parent
  - View Report
  - Add Note

4. System Settings Page

- School profile settings
- User roles and permissions
- Attendance session settings
- Fingerprint device settings
- Notification settings
- Data privacy settings

5. Device Settings Page

- Fingerprint Reader: ZKTeco ZK9500
- Device status:
  - Connected
  - Disconnected
  - Testing
- Buttons:
  - Test Device
  - Reconnect
  - View Device Logs
- Helpful instruction text for admins

6. Final UI Polish

- Add consistent top navigation and sidebar
- Add breadcrumbs
- Add loading states
- Add empty states
- Add confirmation modals
- Add success/error toast notifications
- Add responsive layouts for desktop, tablet, and mobile
- Add clean icons matching the academic/security/attendance theme

UX Requirements:

- Reports should be simple enough for administrators to understand quickly
- Analytics should look useful but not too complicated
- Settings should be grouped clearly
- Keep all pages visually consistent with the RecordIT logo and brand
- The final design should feel ready for development in Next.js
