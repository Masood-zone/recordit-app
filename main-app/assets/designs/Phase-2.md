Design the Super Admin dashboard UI for RecordIT.

RecordIT is a biometric-based multi-school attendance monitoring and reporting system. The theme should follow the logo color system: deep navy, royal blue, cyan, white, and slate gray.

The Super Admin manages multiple schools from one centralized platform.

Create the following screens:

1. Super Admin Dashboard

- Welcome header: Welcome back, Super Admin
- Summary cards:
  - Total Schools
  - Active Schools
  - Total Students
  - Total Teachers
  - Attendance Sessions Today
- Use simple charts for:
  - Attendance activity across schools
  - Schools by status
- Quick action buttons:
  - Add School
  - View Schools
  - Generate Platform Report

2. Schools Management Page

- Table/list of schools
- Columns:
  - School Name
  - School Code
  - Location
  - Admin Contact
  - Status
  - Date Added
  - Actions
- Include search, filter, and status badge
- Actions: View, Edit, Suspend, Activate

3. Add/Edit School Page

- Form fields:
  - School Name
  - School Code
  - Email
  - Phone
  - Address
  - City
  - Region
  - Country
  - Status
- Use a simple form layout with clear section headings

4. School Details Page

- School profile card
- Tabs:
  - Overview
  - Users
  - Students
  - Classes
  - Attendance
  - Reports
- Add clear buttons for managing school users and data

UX Requirements:

- Make it extremely simple and friendly for platform owners
- Use blue/cyan accents for important actions
- Use warning colors only for suspend/delete actions
- Keep spacing clean and professional
- Use modern cards, tables, filters, and empty states
