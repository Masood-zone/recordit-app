Design the Parent/Guardian portal UI for RecordIT.

RecordIT allows parents and guardians to monitor their child’s attendance records. The UI must be extremely simple, friendly, and mobile-first because many parents may access it from phones.

Use the RecordIT logo theme:

- Deep navy
- Royal blue
- Bright cyan
- White
- Slate gray
- Soft light-blue backgrounds

Create the following screens:

1. Parent Dashboard

- Welcome header: Welcome, Parent/Guardian
- Child/ward profile card:
  - Student name
  - Student photo/avatar
  - Class
  - School
- Attendance summary cards:
  - Present Days
  - Absent Days
  - Late Days
  - Attendance Percentage
- Simple message:
  “Your child’s attendance is up to date”
  or
  “Your child has missed attendance recently”

2. Multiple Children View

- If a parent has more than one child, show child cards
- Each card should show:
  - Name
  - Class
  - Attendance percentage
  - View Attendance button

3. Child Attendance Details Page

- Student profile header
- Attendance calendar view
- Color-coded attendance states:
  - Present
  - Absent
  - Late
  - Excused
- Recent attendance list:
  - Date
  - Status
  - Time
  - Teacher/Class session
- Filter by:
  - This Week
  - This Month
  - This Term

4. Notification Preferences Page

- Parent can choose future notification options:
  - Email
  - SMS
  - WhatsApp
  - In-app
- Toggle options:
  - Notify me when my child is absent
  - Notify me when my child is late
  - Send weekly attendance summary

5. Parent Profile Page

- Name
- Phone
- Email
- Relationship
- Linked children
- Edit contact details button

UX Requirements:

- Mobile-first design
- Very simple wording
- Avoid technical terms
- Use clear status badges
- Make attendance information easy to understand at a glance
- Make parents feel informed, not overwhelmed
