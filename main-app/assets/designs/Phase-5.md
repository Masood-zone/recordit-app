Design the Teacher dashboard and attendance-taking interface for RecordIT.

RecordIT is a biometric-based multi-school attendance monitoring and reporting system. Teachers need a very simple and fast interface to take attendance using a fingerprint reader.

Use the RecordIT theme:

- Deep navy
- Royal blue
- Bright cyan
- White
- Slate gray

Create the following screens:

1. Teacher Dashboard

- Welcome header: Welcome, Teacher
- Show assigned classes
- Summary cards:
  - My Classes
  - Students Assigned
  - Attendance Sessions Today
  - Pending Attendance
- Today’s schedule/list of classes
- Quick actions:
  - Start Attendance
  - View Class Attendance
  - View Reports

2. My Classes Page

- Class cards showing:
  - Class name
  - Number of students
  - Attendance status today
  - Start Attendance button
  - View Records button

3. Start Attendance Session Page

- Select class
- Select date
- Select session type:
  - Morning
  - Afternoon
  - Subject/Class Period
- Button: Open Attendance Session
- Display simple instructions

4. Live Biometric Attendance Page

- Big central fingerprint scan area
- Device status indicator:
  - Connected
  - Waiting for student
  - Verifying
  - Student Found
  - Not Found
- When a student is verified, show:
  - Student photo/avatar
  - Student name
  - Student ID
  - Class
  - Attendance status: Present
  - Time recorded
- Include attendance counter:
  - Present
  - Absent
  - Late
  - Total Students
- Recent scans list on the side
- Buttons:
  - Mark Late
  - Mark Excused
  - Close Session
  - View Summary

5. Attendance Session Summary Page

- Class name
- Date
- Teacher
- Total students
- Present count
- Absent count
- Late count
- Excused count
- Student attendance table
- Button: Submit/Close Attendance

UX Requirements:

- Teacher should be able to take attendance with very few clicks
- Make scan feedback very visible
- Use large buttons and readable status messages
- Make the live attendance page feel fast, calm, and reliable
- Include helpful empty and error states
