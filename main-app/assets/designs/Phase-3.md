Design the School Admin dashboard and setup screens for RecordIT.

RecordIT is a biometric-based multi-school attendance monitoring and reporting system. The design should be clean, academic, secure, and friendly. Use the logo-inspired theme: deep navy, royal blue, bright cyan, white, and slate gray.

The School Admin manages students, teachers, parents, classes, academic terms, and attendance settings.

Create the following screens:

1. School Admin Dashboard

- Header: Good morning, Administrator
- School name displayed clearly
- Summary cards:
  - Total Students
  - Total Teachers
  - Total Parents
  - Classes
  - Attendance Today
  - Absentees Today
- Simple chart:
  - Weekly attendance trend
- Quick actions:
  - Register Student
  - Add Teacher
  - Add Parent
  - Create Class
  - Start Attendance Session
  - Generate Report

2. Academic Setup Page

- Manage Academic Years
- Manage Terms
- Manage Classes
- Use tabs or clean cards
- Each item should have Edit, View, Archive actions

3. User Management Page

- Tabs:
  - Administrators
  - Teachers
  - Parents/Guardians
- Table with name, email, phone, role, status, actions
- Search and filter by role/status
- Add User button

4. Add Teacher Page

- Teacher profile form:
  - First Name
  - Last Name
  - Email
  - Phone
  - Staff Number
  - Department
  - Assigned Class
- Simple save button and cancel button

5. Add Parent/Guardian Page

- Parent profile form:
  - First Name
  - Last Name
  - Email
  - Phone
  - Relationship
  - Address
  - Link to Student
- The linking section should be very clear and easy to understand

UX Requirements:

- Admins should see the most important actions immediately
- Use large readable labels
- Use friendly empty states such as “No classes created yet”
- Keep the sidebar simple:
  - Dashboard
  - Students
  - Teachers
  - Parents
  - Classes
  - Attendance
  - Reports
  - Settings
